# Тілашар

Казахский для детей 6–9 лет: ребёнок слушает слово, повторяет за голосом и произносит его в микрофон.
Родитель может записать все слова своим голосом. Этап 1: семейный аккаунт, профили детей, экран дня,
синхронизация прогресса.

```
backend/   FastAPI + PostgreSQL: аккаунты, дети, контент, урок дня, записи голоса
web/       Клиент: нативные ES-модули, без сборщика, PWA с офлайн-режимом
docs/      Контракт API (docs/api.md) — источник истины для обеих сторон
```

## Запуск

```bash
cp .env.example .env         # поправьте JWT_SECRET
make up                      # postgres + api + web
make migrate                 # схема
make seed                    # 6 тем, 50 слов с переводами
```

* приложение — http://localhost:8080
* API и Swagger — http://localhost:8000/docs
* в dev-режиме (`SMS_PROVIDER=console`) код подтверждения всегда `000000` и печатается в лог

Тесты бэкенда идут на SQLite, docker для них не нужен:

```bash
cd backend && pip install -e ".[dev]" && pytest -q
```

## Что уже работает

* вход по номеру телефона и SMS-коду, гостевой режим и перенос гостевого прогресса в аккаунт
* до 4 детей в семье, у каждого свой язык интерфейса (қазақша / русский)
* урок дня: до 8 слов — новые из текущей темы плюс слова на повтор, состав фиксируется на день
* серия дней с «заморозкой»: пропуск одного дня серию держит, два подряд обнуляют
* распознавание речи и оценка произношения — в браузере; на сервер уходят только звёзды и распознанный текст
* записи голоса родителя хранятся в семье и доступны на любом её устройстве
* офлайн: приложение открывается из кеша, попытки копятся в очереди и досылаются при появлении сети
