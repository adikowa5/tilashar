# Тілашар

Казахский для детей 6–9 лет: ребёнок слушает слово, повторяет за голосом и произносит его в микрофон.
Слова озвучивает автор в своём редакторе, а родитель может записать похвалу своим голосом.
Регистрации нет: семья живёт на устройстве, второе устройство подключается по коду семьи.

```
backend/   FastAPI + PostgreSQL: аккаунты, дети, контент, урок дня, записи голоса
public/    Клиент: нативные ES-модули, без сборщика, PWA с офлайн-режимом
           (имя public/ — требование Vercel: оттуда статика отдаётся с корня)
asgi.py    Точка входа для Vercel: поднимает то же приложение как ASGI-функцию
docs/      Контракт API (docs/api.md) — источник истины для обеих сторон
```

## Запуск

```bash
cp .env.example .env         # поправьте JWT_SECRET
make up                      # postgres + api + web
make migrate                 # схема
make seed                    # 6 категорий, 50 слов, 8 фраз похвалы, голос модели
```

* приложение — http://localhost:8080
* API и Swagger — http://localhost:8000/docs
* редактор автора — http://localhost:8080/#author (пароль — `ADMIN_PASSWORD` из `.env`)

Тесты бэкенда идут на SQLite, docker для них не нужен:

```bash
cd backend && pip install -e ".[dev]" && pytest -q
```

## Что уже работает

* вход без регистрации: семья на устройстве, второе устройство — по коду семьи или ссылке `/?join=…`
* редактор автора: категории, слова (по одному и списком), запись голоса, картинки, черновики, статистика
* до 4 детей в семье, у каждого свой язык интерфейса (қазақша / русский)
* урок дня: до 8 слов — новые из текущей темы плюс слова на повтор, состав фиксируется на день
* серия дней с «заморозкой»: пропуск одного дня серию держит, два подряд обнуляют
* распознавание речи и оценка произношения — в браузере; на сервер уходят только звёзды и распознанный текст
* похвала голосом родителя хранится в семье и звучит на любом её устройстве
* офлайн: приложение открывается из кеша, попытки копятся в очереди и досылаются при появлении сети

## Деплой: Vercel + Neon

Один проект на Vercel отдаёт и статику из `public/`, и API из `asgi.py`; база — Postgres на Neon.

1. Создайте базу на neon.tech и возьмите **pooled** строку подключения; замените в ней
   схему на `postgresql+psycopg://`.
2. Накатите миграции и сидинг со своей машины (из serverless-функции это не делается):
   ```bash
   cd backend
   DATABASE_URL='postgresql+psycopg://...neon.tech/neondb?sslmode=require' alembic upgrade head
   DATABASE_URL='...' python -m app.seed
   ```
3. Импортируйте репозиторий на vercel.com/new. Переменные окружения проекта:
   `DATABASE_URL`, `JWT_SECRET` (от 32 символов), `ADMIN_PASSWORD` (пароль редактора),
   `CRON_SECRET` (любая длинная строка — для ежедневной уборки),
   `CORS_ORIGINS` можно оставить пустым — фронт и API на одном домене.
4. Пуш в `main` разворачивает продакшен, любая другая ветка даёт preview-ссылку.

Особенности, которые уже учтены в коде:

* **Нет диска.** Записи голоса лежат в БД и отдаются по `/api/v1/voices/audio/<sha256>.wav`
  без токена: 256-битный хеш не угадать, зато `<audio src>` и кеш service worker работают
  без заголовков.
* **Нет пула соединений.** При `VERCEL=1` SQLAlchemy переключается на `NullPool`,
  соединения держит пулер Neon.
* **Файлы в базе.** Голос и картинки лежат в таблице `media` и отдаются по
  `/api/v1/media/<sha256>.<ext>` с вечным кешем; service worker хранит их для офлайна.
* **Уборка.** В `vercel.json` ежедневный cron на `/api/v1/internal/cleanup`: удаляет брошенные
  семьи, старые счётчики и неиспользуемые файлы. Работает, только если задан `CRON_SECRET`.
